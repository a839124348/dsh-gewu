# 格物 / gewu

> 让模型只看结果，不反复读自己的旧草稿。

## 解决了什么

长会话聊到后面，模型开始在思考里念叨：

> 做。做。做。做。

这不是它在想，是它在反复读自己的旧草稿。格物把那些草稿挡在上下文之外 —— 只留最近几步，接住当前这一轮。

说过的话、工具调用、工具结果，一条不少。

## 怎么安装

把 [INSTALL-FOR-AI.md](INSTALL-FOR-AI.md) 整份发给 DSH 里的模型，说一句：

> 按这份说明装。

它会自己备份配置、加三行、让你重启。

手动装也行，在 `~/.dsh/profiles/web/cordis.patch.yml` 末尾加：

```yaml
- insert:
    - id: gewu
      name: 'D:/你的路径/gewu.js'
      config:
        keepLast: 3
```

## 怎么检验

1. 启动日志出现 `[gewu] 已启用：保留最近 3 条思考`
2. 聊几轮后出现 `[gewu] 已摘 N 条 / X 字`
3. 问它一句："你前面几轮思考里都写了什么？" —— 应该只剩最近 3 条
