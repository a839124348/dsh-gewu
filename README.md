# 格物 / gewu

> 让模型只看结果，不反复读自己的旧草稿。

长会话聊到后面，模型开始在思考里念叨：

> 做。做。做。做。

这不是它在想，是它在反复读自己的旧草稿。格物把那些草稿挡在上下文之外 —— 只留最近几步，接住当前这一轮。

说过的话、工具调用、工具结果，一条不少。

> **v0.2.0 换了实现**：从「改写会话」改成「只读投影」——不写日志、不碰历史，原文还在。
> **v0.1.0 在 DSH 0.1.3+ 上无效**（assistant 消息不允许替换），装了请直接升级。

## 解决了什么

长会话里，DSH 会把过去每一轮的思考重新上传一遍。结果是：

- 模型开始模仿自己，重复的短句越滚越牢
- 旧的猜测被下一轮当成事实
- 20%~45% 的上下文被草稿占着

格物在模型读取历史的那一刻，把「最近几步之外」的思考摘掉。

## 怎么安装

把 [INSTALL-FOR-AI.md](INSTALL-FOR-AI.md) 整份发给 DSH 里的模型，说一句：

> 按这份说明装。

它会自己备份配置、加三行、让你重启。

手动装也行，在 `~/.dsh/profiles/web/cordis.patch.yml` 末尾加：

```yaml
- insert:
    - id: gewu
      name: 'D:/你的路径/gewu.js'
      config:
        keepLast: 3
```

## 怎么检验

1. `~/.dsh/gewu/gewu.log` 里出现 `[gewu] 已挂载 session=...`
2. 聊几轮后出现 `[gewu] 已摘 N 条 / X 字`
3. `~/.dsh/gewu/stats.json` 里有当前会话的水位

桌面版的控制台不落盘，所以日志写在文件里，不用去翻终端。

## 兼容

- DSH 0.2.x（实测 0.2.2-rc.1），0.1.3+ 都能用
- 依赖 DSH 内部方法 `deriveMessages` / `deriveEventMessage`；哪天改名了，日志里会写 `[gewu] 挂载失败`，对话照常
- 和核星记忆互不影响
