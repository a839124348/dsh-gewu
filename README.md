# 格物 / gewu

> 让模型只看结果，不反复读自己的旧草稿。

长会话聊到后面，它开始在思考里念：

> 做。做。做。做。

那不是它在想，是它在回头读自己的草稿。格物把那部分轻轻放下 —— **当前轮留着，往轮全部放下**。

**当前版本 v0.3.0** · 更新日志见 [CHANGELOG.md](CHANGELOG.md)

> ⚠️ 如果你装过 v0.2.x 并且发现**账单变贵了**，那不是错觉，是那一版的实现缺陷（滑动窗口每一步都在打碎前缀缓存，实测把输入费用抬高 50%~190%）。
> **v0.3.0 修掉了这个问题。** 具体数据在 [CHANGELOG 的 v0.3.0 一节](CHANGELOG.md#030---2026-11-18)。
> 升级时记得把配置里的 `keepLast` 删掉或改成 `keepTurns`。

## 你会得到什么

**上下文更宽裕**

过去每一轮的草稿都会长在上下文里，占掉 20%~45%。放下它们之后，同样的窗口能装下更多你们真正聊过的内容，压缩也会晚一点来。

**思考更清爽**

模型不再一遍遍读到自己的旧稿。重复的短句、越滚越牢的口头禅，慢慢就失去了土壤。

**该在的，一条不少**

说过的话、工具调用、工具结果，原样保留。放下的只是草稿；原文仍在本机日志里，想查随时能查。

## 它省上下文，不省账单

这一条要写清楚，免得装完发现账单变贵。

现在的计费按「前缀缓存」算：从请求开头逐个 token 比对，一旦某处不一样，后面全部按未命中重算。命中通常便宜 10 倍。

所以判断格物值不值，不是看「少发了多少 token」，而是看「有没有把前缀打碎」：

- **当前轮内**：摘掉的集合完全不变 → 前缀不打碎 → 省下的就是净省的
- **换轮那一刻**：上一轮整体转为摘掉 → 前缀断一次 → 这一次要重算

实测你机器上 12 个真实会话（236 步，DeepSeek 口径 命中 0.1x / 未命中 1.0x）：

| 版本 | 输入费用 | 上下文 |
|:--|:--|:--|
| 不装 | ×1.00 | 0% |
| **v0.2.x（保留最近 N 条）** | **×1.52** | −10.9% |
| **v0.3.0（按轮切）** | **×1.08** | **−16.4%** |

v0.2.x 那个 ×1.52 是设计缺陷：`keepLast` 是滑动窗口，每来一条新消息窗口就往前挪一格，把一条原本保留的变成摘掉 —— 这一步就是前缀断点。所以它一边省 token，一边把后面几千字全部按未命中重算，净亏。

v0.3.0 改成按轮切，摘掉的集合只增不减，前缀只在换轮时断一次。

**结论**：DeepSeek 官方口径下约等于「不涨不跌，白赚 16% 上下文」；缓存折扣更小的中转上才是真省钱（0.25x 口径实测 ×0.96）。如果你的目标纯粹是降低账单，不装最省。

## 怎么安装

把 [INSTALL-FOR-AI.md](INSTALL-FOR-AI.md) 整份发给 DSH 里的模型，说一句：

> 按这份说明装。

它会自己备份配置、加三行、让你重启。

手动装也行，在 `~/.dsh/profiles/web/cordis.patch.yml` 末尾加：

```yaml
- insert:
    - id: gewu
      name: 'D:/你的路径/gewu.js'
      config:
        keepTurns: 1
```

| 配置 | 默认 | 说明 |
|:--|:--|:--|
| `keepTurns` | `1` | 保留最近几**轮**的思考（不是几条）；最小 1（0 会按 1 处理） |
| `dryRun` | `false` | 只统计，不改视图 |
| `skipProviders` | `[]` | 不动的 provider（见下面「中转」） |

**从 v0.2.x 升级**：老配置里的 `keepLast: 3` 已经废弃。留着不会报错（日志会提醒一句），但会按 `keepTurns: 1` 处理。建议直接删掉那一行。

## 怎么检验

1. `~/.dsh/gewu/gewu.log` 里出现 `[gewu] 已挂载 session=...`
2. 聊几轮后出现 `[gewu] 已摘 N 条 / X 字`
3. `~/.dsh/gewu/stats.json` 里有当前会话的水位

桌面版的控制台不落盘，所以日志写在文件里，不用去翻终端。

## 一句实话

它管的是「跨轮」—— 不让旧草稿一轮轮叠上来。

如果某一步里已经卡在“写。做。写。做。”，那得靠换口气：换个语言想，或者开个新会话。这一层插件帮不上忙。

## 兼容

- **适用 DSH 0.2.x**（实测 0.2.2-rc.1、0.2.1-rc.3）。0.2.0 及更早没有实测过，装之前先备份 profile
- **v0.1.0 在 DSH 0.1.3+ 上无效**，装了旧版的直接覆盖升级，配置不用改
- 依赖 DSH 内部方法 `deriveMessages` / `deriveEventMessage`；哪天改名了，日志里会写 `[gewu] 挂载失败`，对话照常
- 和核星记忆互不影响

**如果装上 DSH 起不来**：先把 `cordis.patch.yml` 里那段 `insert` 删掉、重启，确认能启动，再看日志找原因。最常见的是**同一个 `id: gewu` 写了两遍**，或者路径不对。

## 中转

有些第三方网关没有字段承载上游的思考签名，只能靠「回放思考文本取哈希」来重建对话状态。
把旧的思考摘掉，它会查无此签名，偶发对不上。

遇到这类报错，把 provider 名加进 `skipProviders`（日志里会打出 `[gewu] provider=...`）：

```yaml
config:
  skipProviders:
    - 你的provider名
```

官方 API 不用管这一条。
